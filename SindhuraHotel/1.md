# Banquet Hall Booking System

## Description
This is an end to end pipeline for banquet hall bookings for Hotel Sindhura East Court.

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MySQL

## Features
- User registration & login
- Booking system
- Admin approval/rejection
- Real-time Booking status tracking
- SuperAdmin to approve other admins.


## How to Run

### Backend
cd backend
npm install
node server.cjs

### Frontend
cd src
npm install
npm run dev
